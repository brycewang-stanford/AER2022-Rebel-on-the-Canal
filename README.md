# AER 2022 — Rebel on the Canal

> Cao & Chen (2022), *American Economic Review* 112(5): 1555–1590.
> **"Rebel on the Canal: Disrupted Trade Access and Social Conflict in China"**

A reading-and-replication workspace for the above paper, built on the official replication package (AEA openICPSR **157781-V1**).

## Layout

```text
.
├── Data/                  原始数据 — openICPSR 157781-V1 (local only, not tracked by git)
│   ├── Raw/               rebellion records, CHGIS shape files, GTOPO30, GAEZ, Mann climate, …
│   ├── Interim/           generated by Program/Clean/clean.do
│   └── Final/             rebellion.dta, generated by Program/Clean/clean.do
├── Program/               原始代码 — author's replication code
│   ├── master.do          entry point: cleans data, then runs every figure/table
│   ├── setup.do           installs user-written Stata packages
│   ├── Clean/             clean.do, clean_mann.do, clean_ruggedness.do
│   ├── Analysis/          figure*/table*.do + generalsetup.do, generalnotes.do
│   ├── Maps/              ArcMap packages (*.mpk) for Figures 1, 3, B1–B3, C1–C6a
│   └── Adofile/           spatial_HAC (Hsiang 2010 Conley SE) + source.txt
├── Results/               output of master.do
│   ├── overview.tex       LaTeX file that collects all figures and tables
│   ├── Figures/           (generated, not tracked)
│   └── Tables/            (generated, not tracked)
└── Materials/             其它材料 — paper, package README, reading notes, DID references
    ├── AER2022-Rebel on the Canal- ….pdf
    ├── 157781-V1-Readme.pdf   official package README (data provenance, instructions)
    ├── Rebel on the Canal (AER 2022).md
    ├── 论文模型解读与StatsPAI复现分析.md
    ├── attachments/       figures embedded in the Obsidian note
    └── docs/              staggered-DID command references, StatsPAI notes, working specs
```

`Program/` and `Data/` keep the author's folder names on purpose: every script uses paths relative to the project root (`Program/...`, `Data/Raw/...`, `Results/Tables/...`).

## How to run

1. Put the openICPSR raw data in `Data/Raw/` (already in place on the author's machine; not on GitHub — see [Data/README.md](Data/README.md)).
2. Edit the `cd` line in `Program/master.do` — replace `D:/FullReplication` with your local project root (the folder containing `Program/` and `Data/`).
3. From Stata: `do Program/master.do`. The package README reports about 1 hour of run time; the 11 maps are made in ArcMap from `Program/Maps/*.mpk`, not by Stata.
