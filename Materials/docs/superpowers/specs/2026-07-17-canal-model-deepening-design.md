## 6. 章节详细规范

### 5.1 潜在结果框架与基准 DID

- **(i)** 个体潜在结果 $Y_{ct}(0)$、$Y_{ct}(1)$，处理变量 $D_{ct} = AlongCanal_c \times Post_t$，观测 $Y_{ct} = Y_{ct}(0) + \tau_{ct} D_{ct}$；
- **(ii)** 式 (1)：$Y_{ct} = \beta \, D_{ct} + \delta_c + \sigma_t + \chi_{ct} + \varepsilon_{ct}$，≡ Table 3；
- **(iii)** 关键假设：平行趋势 $\mathbb{E}[Y_{ct}(0) \mid D_c=1, t] - \mathbb{E}[Y_{ct}(0) \mid D_c=0, t] = \alpha$ 常数；SUTVA；线性条件均值；共同冲击同质；
- **(iv)** 用 5.2 的事件研究 (式 2) + 前趋势 (式 3) 验证平行趋势；5.6 的 CIC/SCM 放松同质共同冲击假设；
- **(v)** β̂ = 0.0380 (Table 3 列 1)，对应 exp(0.0380)−1 = 0.0387 / 0.0330 ≈ 117%。

### 5.2 事件研究 (式 2) 与前趋势 (式 3)

- **(i)** 平行趋势是 DID 的关键假设，需要分时段验证；
- **(ii)** 式 (2)：$Y_{ct} = \sum_{\tau=-50}^{70} \beta_\tau \, AlongCanal_c \times Decade^\tau_t + \delta_c + \sigma_t + \chi_{ct} + \varepsilon_{ct}$，参照组 = 1826 年前 ≥ 50 年，≡ Figure 4；
- **(iii)** 等价于把 $D_{ct}$ 拆为按十年分箱的滞后/前瞻交互，每一 bin 一个 βτ；
- **(iv)** 论文做：1826 年前各 bin 系数应为零（平行趋势）；1826 年后系数先升（30 年代运量降）→ 1840 年代永久改革推进再升 → 1865 年达峰 → 1870s 收敛；式 (3) 把样本限制在 1776-1825 年，估计 $AlongCanal_c \times Year_t$（连续时间趋势），系数应为零，≡ Table 2。
- **(v)** Table 2 全部接近 0 且不显著，验证识别可信。

### 5.3 处理强度模型 (式 4-5)

- **(i)** 二值处理假设"处理均匀、止于县界"过强，沿河越长的县应受创越重、市镇沿河越密的县受创越重；
- **(ii)** 式 (4) 线性：$Y_{ct} = \beta CanalIntensity_c \times Post_t + \delta_c + \sigma_t + \chi_{ct} + \varepsilon_{ct}$，$Intensity \in \{CanalLength/100km^2,\ CanalTownShare\}$；式 (5) 分组：$\sum_k \beta_k IntensityGroup^k_c \times Post_t$；
- **(iii)** 同式 (1)；额外需要处理强度本身的外生（论文论证处理强度由历史地理决定，与战后叛乱倾向无直接关联）；
- **(iv)** ≡ Table 4 列 1-3 (linear)、≡ Online Appendix Figure A3 panel (a) CanalLength、(b) CanalTownShare；
- **(v)** CanalLength×Post = 0.0200 (sig.)；CanalTownShare×Post = 0.0770 (sig.)；长度 < 2 km/100km² 的县与非运河县无异。

### 5.4 空间衰减 (式 6-7)

- **(i)** 越靠近运河的县应受创越重；外溢到 150km 与市场可达性的物理距离吻合；
- **(ii)** 式 (6) 线性：$Y_{ct} = \beta Distance_c \times Post_t + \delta_c + \sigma_t + \chi_{ct} + \varepsilon_{ct}$；式 (7) 分组：按 25km 分段，每段一 βk，参照 = 400km 以外；
- **(iii)** 同 5.3；参照组独立性靠 400km 距离阈值保障；
- **(iv)** ≡ Table 4 列 3、≡ Online Appendix Figure A4；
- **(v)** β̂ = −0.0142 (1% sig.)；>150km 与参照组无异。

### 5.5 替代估计技术：CIC 与 SCM

- **(i)** DID 假设处理效应同质。19 世纪中叶有共同的全国动荡，担心"叛乱倾向县"对共同冲击反应更大；用两种非参数方法放松：
  - CIC (Athey-Imbens 2006)：非参数恢复整个反事实分布，估计分位数处理效应 (QTE)；
  - SCM (Cavallo et al. 2013)：为每个处理单元单独构造合成控制；
- **(ii)** CIC 用 Melly-Santangelo (2015) 两步法：第一步 OLS 残差化（控制 FE/协变量），第二步对残差做无条件 CIC 估计分位数处理效应，≡ Online Appendix Figure A5；SCM 用 Cavallo et al. 扩展：每个运河县用一个加权非运河县组合（限制 donor pool ≥ 150km 防外溢污染），加总平均得总效应，RI 做推断，≡ Online Appendix Figure A6；
- **(iii)** 两者均不要求处理效应同质或反事实分布同形；CIC 要求时间不变、SCM 要求"反事实由 donor 加权近似"；
- **(iv)** CIC：全分布上均显著正效应；效应集中在分布**左尾**（原本和平的县）——若"叛乱倾向县对乱世更敏感"假设成立，效应应在右尾，证据相反。SCM：合成控制组 30 年后也出现全国动荡期高峰，进一步排除"运河县对全国动荡更敏感"。
- **(v)** 两条独立证据共同支持"识别不依赖反事实分布同形"。

### 5.6 安慰剂检验与三重交互

- **(i)** 三重担忧：南北差异、其他交通线混淆、鸦片战争/太平天国扰动；
- **(ii)** 式表达为：$Y_{ct} = \beta_1 D_{ct} + \beta_2 D_{ct} \times North_c + \beta_3 North_c \times Post_t + \delta_c + \sigma_t + \chi_{ct} + \varepsilon_{ct}$，或其他交通线指标 Along_AltRiver_c × Post_t；鸦片战争/太平天国 = 战区虚拟变量 × Post_t；
- **(iii)** 论文外生性：北段因黄河淤塞彻底断航、南段仍可承担江浙至上海的转运；其他交通线（长江、黄河、海岸、驿道）未经历类似废弃；鸦片战争/太平天国的影响范围与运河北段不重合；
- **(iv)** ≡ Table 5 (南北)、≡ Table 6 (其他交通线)、≡ Table 7 (大事件)；
- **(v)** North × Post × AlongCanal 三重交互 = 0.0687-0.0998 (1% sig.)；南段效应近零；其他交通线全部不显著；剔除鸦片战争/太平天国战区后系数不减反增（0.0438/0.1032），太平天国战区反而减少（−0.0928）——倾向叛乱者直接加入太平军（替代效应），与史学一致。

### 8.1 排除渠道：国家镇压能力

- **(i)** 竞争解释：运河废弃 → 政府撤减沿线控制 → 叛乱因成功率上升而增加；
- **(ii)** 三重交互：$Y_{ct} = \beta_1 D_{ct} + \beta_2 D_{ct} \times Soldiers_c + \beta_3 D_{ct} \times PrefectureCapital_c + \delta_c + \sigma_t + \chi_{ct} + \varepsilon_{ct}$，以及把结果变量换成"被现有叛军攻击/被撤入的次数"作为安慰剂；
- **(iii)** 1750 年代驻军规模 (Luo 1984) 与是否府治作为改革前政治控制强度的代理；
- **(iv)** ≡ Online Appendix Table A4；
- **(v)** 三重交互均不显著 → 政治控制收缩不解释效应。攻击/撤入的安慰剂结果：被攻击频率**下降**（5% sig.），未被撤入 → 占领运河县的战利品价值下降、不是更安全退路。

### 8.2 确认渠道：贸易可达性丧失

- **(i)** 4 条一致证据（市镇发育、替代通道、风险缓释、跨 150km 衰减）；
- **(ii)** 第一条：$Markets1820_{c}$ 与 $Markets1911_{c}$ 对 $CanalLength_c$ 回归；第二条：$Y_{ct} = \beta_1 D_{ct} + \beta_2 D_{ct} \times Courier_{c} + \delta_c + \sigma_t + \chi_{ct} + \varepsilon_{ct}$；第三条：$Y_{ct} = \beta_1 CanalLength_c \times TemperatureAnomaly_{ct} \times Post_t + \delta_c + \sigma_t + \chi_{ct} + \varepsilon_{ct}$；
- **(iii)** 假设一：1820 年市镇沿河密度反映运河经济功能；假设二：北方陆路驿道是真正的替代通道（运能下降不到 10 倍）；假设三：温度异常是外生冲击（Burgess-Donaldson 2010）；
- **(iv)** ≡ Online Appendix Table A5 列 1-3；
- **(v)** 运河强度 × Post 显著负 → 沿线市镇发展被抑制；Courier 三重交互负且显著 → 有替代通道的县受害更小；Canal×TempAnomaly 三重交互在通航期显著（缓释），废弃后消失（不再显著）。

### 8.3 谁受了冲击：城市贸易从业者

- **(i)** 收入冲击归谁：农产品渠道（消费者/生产者受损）vs 城市贸易从业者渠道（水手/码头工人/商贩失业）；
- **(ii)** 农产品渠道：粮价对废弃回归 + 稻麦适宜度三重交互（应有正效应则支持）；城市渠道：$Y_{ct} = \beta_1 CanalLength_c \times Post_t$ 在距长江 100/200/300/400 km 子样本；
- **(iii)** 粮价数据：Chen and Kung (2016)，基于 Wang (2008)；适合度：FAO GAEZ；距长江子样本：仅取与长江交汇处附近的运河县，长江与运河服务不同方向（南北 vs 东西），人力资本可迁移但市场份额不重叠；
- **(iv)** ≡ Online Appendix Table A6 列 1 (粮价)、列 2-3 (稻麦适宜度)、≡ Online Appendix Figure A7 (距长江)；
- **(v)** 粮价系数正但不显著 → 农产品渠道不解释；距长江越远点估计越大（CI 宽，方向支持）→ 城市贸易从业者失业是主渠道。

### 8.4 长期回响：青帮与秘密会社

- **(i)** 历史叙事：漕运水手行会（漕帮）→ 失业 → 转型秘密会社 → 捻军、义和团、青帮；
- **(ii)** 横截面相关：青帮高阶成员出生地与运河位置的相关系数；
- **(iii)** 数据：《青帮通草汇海》高阶成员名录（横截面）；非因果，但与"运河废弃 → 城市失业 → 组织化暴力延续至 20 世纪"叙事一致；
- **(iv)** ≡ Online Appendix Table A7；
- **(v)** 早期青帮头目高度集中于运河沿线；呼应 Dell-Feigenberg-Teshima (2019) 墨西哥、Haller (1971) 芝加哥、Critchley (2008) 纽约的有组织犯罪起源研究。
